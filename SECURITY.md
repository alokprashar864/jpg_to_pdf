# Security Policy

## Supported Versions

We actively provide security updates and patches for the following versions of the platform:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of this project and user data privacy very seriously. If you discover a security vulnerability or sensitive data leakage risk, please follow responsible disclosure guidelines:

1. **Do NOT report security vulnerabilities through public GitHub issues.**
2. Please report the issue privately using **[GitHub Security Advisories](https://github.com/alokprashar864/jpg_to_pdf/security/advisories/new)** (or by contacting the maintainers directly).
3. Include detailed information:
   - Steps to reproduce or proof of concept.
   - The affected component (e.g. Frontend, NestJS API, Go Worker daemon, Cloudflare R2 presigned URLs).
   - Potential impact of the vulnerability.

### What to Expect

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment:** We will validate the issue and confirm whether a patch is required.
- **Remediation:** Once a fix is verified, we will release a security patch and credit the reporter in the release notes (unless requested otherwise).
